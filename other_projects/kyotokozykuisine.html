KyotoKozyKuisine - Web-Based Hotel and Restaurant Booking Platform

KyotoKozyKuisine is a web-based booking and exploration platform designed to streamline itinerary planning for tourists in Kyoto by seamlessly integrating hostel reservations with dining discovery, thereby eliminating the tedious manual process of cross-referencing maps to find restaurants near a booked accommodation.

To power the feature that recommends restaurants within a 5km radius of a user's chosen hostel, the project uses a hybrid database architecture. MySQL manages structured transactional data like users, bookings, and reviews to ensure data integrity. MongoDB handles dynamic user profiles and geospatial data, using $near and $geometry queries to fetch nearby dining options. Linking both databases with shared primary IDs creates a denormalized structure that boosts read efficiency, transforming manual travel planning into a seamless experience based on location.


Key Features

  • Location-Aware Restaurant Discovery: Automatically recommends dining options within a 5km radius of a user's booked hostel using MongoDB geospatial queries.
  • Unified Booking Management: Provides a comprehensive, chronological history of upcoming and past reservations for both hostels and restaurants.
  • Review and Rating System: Allows users to leave feedback and displays aggregated ratings and average pricing to aid decision-making.
  • Advanced Search and Filtering: Enables wildcard name searches and filtering of hostels and restaurants based on minimum average review ratings.
  • Dynamic User Profiles: Utilizes a flexible NoSQL structure to store and update optional user details like biographies, interests, and social media links.
  • User Analytics and Ranking: Employs SQL window functions to rank users by review frequency and analyze name popularity for business insights.
  • Hybrid Data Integrity: Ensures strict security and referential integrity across relational and non-relational databases using shared identifiers and cascading constraints.
