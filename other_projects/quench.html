Quench E-Commerce Web Application

Quench is an e-commerce web application designed for a company specializing in high-quality, aesthetic water bottles. The project was developed to provide customers with a seamless online shopping experience, from browsing products to secure checkout, while giving administrators full control over inventory and user management. Built using a standard web stack (HTML, CSS, JavaScript, PHP, and MySQL) alongside Bootstrap for mobile responsiveness, the application prioritizes security and quality through session-based access control, SQL prepared statements, and strict input validation, ultimately achieving full W3C and WCAG compliance with zero software vulnerabilities.

Technologies Used

Frontend: HTML5, CSS, JavaScript, Bootstrap, SVG

Backend: PHP, PHP Sessions

Database: MySQL, SQL

Others: Google Maps API, WhatsApp API, W3C Validator, Axe DevTools, ImmuniWeb, Apache/Nginx

Key Features

  • Secure User Authentication & Role Management: Comprehensive account lifecycle including registration, login, and profile editing, utilizing PHP sessions to enforce strict role-based access control for both customers and administrators.
  • Dynamic Product Browsing & Filtering: An interactive shop interface allowing customers to search for specific water bottles using keyword matching and filter by categories, complete with detailed individual product views.
  • Shopping Cart & Wishlist Management: A seamless shopping experience enabling users to add items to a persistent cart, adjust quantities, save favorite products to a wishlist, and easily transfer wishlist items to the cart.
  • Secure Checkout & Order Processing: A streamlined payment page with strict client-side validation for card details, generating real-time order summaries and securely processing transactions to update purchase histories.
  • Comprehensive Admin Dashboard: Exclusive administrative tools to manage inventory by adding or removing products, and oversee user accounts by promoting, demoting, or deleting registered users.
  • Interactive Customer Engagement: Engaging informational pages featuring an embedded interactive Google Map for the office location, and a floating WhatsApp button linked to a number for instant direct communication.
